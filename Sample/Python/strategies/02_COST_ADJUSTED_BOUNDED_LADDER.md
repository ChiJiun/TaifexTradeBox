# 策略二：成本調整後的有限攤平階梯

## 目標

首筆被動進場成交後，價格若短暫往不利方向移動，以有限層數加碼降低平均成本，使價格只需小幅反彈即可費後正報酬退出。

這不是無上限馬丁格爾。它必須同時具備：

- 事前限定層數。
- 依成本計算口數。
- 明確的最終停損。
- 波動及訂單流毒性過濾。

## 平均成本

以多單為例，第 `i` 層買價及口數為：

```text
p_i = p_0 - i * tau
q_i = 第 i 層口數
```

總口數與均價：

```text
Q_N = sum(q_i, i=0..N)
p_bar_N = sum(q_i * p_i, i=0..N) / Q_N
```

若希望從最深層價格 `p_N` 反彈 `R` 跳後退出，則候選退出價為：

```text
p_exit = p_N + R * tau
```

必須再檢查該價格是否足以覆蓋全部進出成本。

## 離散成本條件

若最終在 `p_0 - m*tau` 出場，毛利的「跳數乘口數」為：

```text
U = sum(q_i * (i - m), i=0..N)
```

令每口來回成本相對於一跳契約價值的比例為：

```text
kappa = C(P) / (M * tau)
```

費後正報酬條件：

```text
U > kappa * Q_N
```

這個條件應使用當下商品價格、實際手續費和稅率計算，不能永久沿用歷史隊伍的固定口數。

## 最後一層最小口數

若前 `N-1` 層已有：

```text
Q_prev = sum(q_i, i=0..N-1)
U_prev = sum(q_i * (i - m), i=0..N-1)
```

則最後一層最小加碼量須滿足：

```text
q_N > (kappa * Q_prev - U_prev) / (N - m - kappa)
```

只有在 `N - m > kappa` 時，此退出設計才可能用有限口數達成。

實作時應向上取整數，並再受 `max_inventory`、保證金與損失預算限制。

## 4、2、5 的數學意義

假設：

- 4 口買在 `p_0`。
- 2 口買在 `p_0-1*tau`。
- 5 口買在 `p_0-2*tau`。
- 反彈一跳，在 `p_0-1*tau` 出場。

則：

```text
U = 4*(-1) + 2*0 + 5*1 = 1
Q = 11
```

標準台積電若價格約 1,000 元、競賽手續費每口單邊 50 元：

```text
C(P) ~= 180
kappa ~= 180 / 2000 = 0.09
kappa * Q ~= 0.99
```

因此 `U=1` 只比成本門檻 `0.99` 略高。4、2、5 幾乎正好是讓最深層成交後反彈一跳即可略為獲利的整數組合。

若台積電價格提高到約 2,300 元：

```text
C(P) ~= 284
kappa ~= 0.142
kappa * Q ~= 1.562
```

此時 4、2、5 在相同退出價會虧損，最後一層至少約需 6 口。這證明階梯口數必須隨價格與成本更新。

## 風險條件

對多單，若最終停損價為 `p_stop`，最大毛損失為：

```text
L_gross = M * sum(q_i * (p_i - p_stop))
```

費後最大損失為：

```text
L_max = L_gross + entry_costs + exit_costs
```

若成功退出淨利為 `G`，最基本的損益兩點模型要求成功率：

```text
p_win > L_max / (G + L_max)
```

例如 4、2、5 在 `p_0` 出場約可取得 24,000 元毛利；若跌到 `p_0-5*tau` 才停損，毛損失約 86,000 元。扣入費用後，所需成功率約在 81% 左右。停損越遠，必要成功率越高。

## 狀態機

### `LEVEL_0`

- 首筆入口成交。
- 建立費後退出單。
- 記錄初始價格、數量與循環風險預算。

### `LEVEL_1`、`LEVEL_2`

- 價格到達下一層門檻。
- 只有在波動未超標、成交流不再強烈逆向時才允許加碼。
- 用公式計算最小加碼量，超出庫存或損失上限則不加碼並轉入退出。
- 每次成交後重新計算真實均價與退出價。

### `FINAL_LEVEL`

- 絕不再加碼。
- 只等待目標價、停損、持倉逾時或收盤退出。

### `STOPPED`

- 停損後當日降低基礎口數或停止策略。
- 不允許因上一循環虧損而在下一循環加倍。

## 建議限制

- 最大階梯層數：2 或 3。
- 每層間距：1、2、3 跳進行比較，不應只測一跳。
- 單循環最大損失：以前一日權益固定比例表示。
- 階梯全部成交時，原始保證金占權益不得超過預設比例。
- 開盤急波動、重大跳空及尾盤禁止啟動新階梯。

## 失效條件

- 趨勢行情沒有足夠反彈。
- 最深層只部分成交，實際均價不符合預計。
- 出口需要的真實量不足。
- 波動和不利成交流具有群聚性，導致階梯在最差時機全部成交。
- 商品價格上升後成本比例改變，但口數仍沿用舊參數。
