# 策略四：競賽每日損益塑形與資格管理

## 目標

縱橫期海競賽先從合格隊伍中取每日報酬夏普前 30 名，再依總獲利取前 15 名。因此正確目標不是單獨最大化夏普，也不是完全忽略夏普追求最高獲利，而是：

```text
maximize total_profit
subject to:
    total_profit > 0
    Sharpe_rank <= 30
    active_days >= 28
    product_categories >= 6
    report_approved = true
```

官方夏普為：

```text
r_d = (E_d - E_{d-1}) / E_{d-1}
Sharpe = mean(r_d) / stdev(r_d)
```

它沒有年化，因此單日損益離群值會直接影響排名。

## 每日獲利封頂

每日開始時依前日權益設定目標：

```text
H_d = h * E_{d-1}
```

當日已實現損益加保守未實現損益達到 `H_d` 時：

1. 取消所有入口單。
2. 只處理現有部位。
3. 平倉後鎖定當日停止狀態。

原因是達標後繼續交易雖可能提高當日獲利，但也可能把一個穩定正報酬日變成負報酬日。對每日夏普而言，避免獲利回吐通常比擴大單日右尾更重要。

## 每日損失與回撤停機

設定：

```text
D_d = d * E_{d-1}
MDD_d = m * E_{d-1}
```

- 當日權益低於開盤權益 `D_d`：停止。
- 當日高點至目前權益回撤超過 `MDD_d`：停止。
- 停止狀態必須鎖定到下一交易日，不能因程式重新啟動而解除。

高勝率小利策略最怕單日尾部損失一次吃掉多日獲利。每日損失上限的主要目的，是保護夏普與避免保證金風險，而不是提高逐筆勝率。

## 權益比例口數

不建議在虧損循環後提高下一循環口數。較合理的放大方式是隨權益成長：

```text
q_base_d = floor(k * E_{d-1} / margin_per_contract)
```

其中 `k` 是保證金使用比例，還須同時滿足：

```text
worst_cycle_loss(q_base_d) <= cycle_risk_budget
total_margin <= margin_budget
```

若有可靠的循環報酬分布，可用分數 Kelly：

```text
f_star = argmax_f E[log(1 + fR)]
f_used = c * f_star,  0 < c <= 0.25
```

實務上只使用 0.1 至 0.25 Kelly，可降低勝率與尾部損失估計錯誤造成的過度槓桿。

## 夏普緩衝

官方只公布得獎隊伍，不一定公開完整第 30 名夏普門檻，因此策略應保留緩衝。

研究上可設定：

```text
target_sharpe = 0.40
warning_sharpe = 0.30
```

這只是內部風控候選值，不是官方資格線。當滾動估計低於警戒值時，可降低口數、縮短交易時段或提高訂單流門檻。

## 資格管理

### 六項商品

- 主策略可集中在台積電期貨。
- 其餘商品用小口數、短持倉完成有效交易。
- 不要等最後一週才補足商品種類，以免被迫承擔不必要波動。
- 每項交易都應有正常市場理由與風險限制，不使用純粹異常成交方式灌資格。

### 二十八個成交日

- 以至少 35 至 40 個有效成交日為內部目標，預留斷線、休市或無成交日。
- 每日只需有真實有效成交，不必為增加天數放大部位。

### 程式交易紀錄

- 保留每日行情、送單、撤單、成交、權益及錯誤紀錄。
- 每日結束產生資格檢查：商品種類、成交日數、總損益、日夏普與心得報告狀態。

## 兩階段競賽配置

### 階段 A：建立資格與夏普

- 使用較小基礎口數。
- 每日獲利目標較低。
- 優先累積穩定正報酬日。
- 提前完成六項商品。

### 階段 B：在夏普有緩衝後擴大利潤

- 只按權益成長增加口數。
- 保留相同的每日損失比例。
- 不因排行榜落後而取消最終停損。
- 每週重新以過去資料估計達標機率，但不得用未來資料選參數。

## 失效條件

- 每日獲利封頂太低，使總獲利無法進入前 15。
- 封頂後仍持有未平倉風險，導致帳戶總市值波動。
- 用當期排行榜反覆調參造成追逐噪音。
- 只計已實現損益，忽略未實現虧損對每日總市值的影響。
- 資格交易集中在最後階段，干擾主策略。
