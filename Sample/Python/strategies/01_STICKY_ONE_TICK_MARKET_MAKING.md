# 策略一：黏著式一跳被動做市

## 目標

在高成交量、通常維持一跳買賣價差的商品上，將限價單預先留在最佳買價或最佳賣價，利用模擬撮合不必爭奪真實排隊順位的特性，反覆完成「被動進場－一跳被動出場」循環。

這是所有策略的基礎。它不需要預測數十跳行情，只要求後續真實市場再次在相鄰價位出現符合條件的價量。

## 為什麼有效

真實市場的最佳買價可能已有大量委託排在前方；新單即使看到成交，也未必輪得到。虛擬交易所則把每位模擬交易人的委託獨立拿去和真實行情比對，因此排隊成本大幅降低。

但委託仍須在符合條件的行情事件之前存在。若策略看到每個 tick 都立刻撤單追價，新單可能永遠晚於剛發生的成交。因此報價必須具有黏著性。

## 商品選擇分數

對商品 `j` 定義每單位保證金的預期獲利速度：

```text
score_j = lambda_j * p_cycle_j * G_j / Margin_j
```

其中：

- `lambda_j`：每單位時間可遇到的有效觸價事件數。
- `p_cycle_j`：進場和出場都能完成的機率。
- `G_j`：一次循環費後淨利。
- `Margin_j`：占用的原始保證金。

標準台積電期貨的優勢來自高成交量、一跳約 2,000 元的契約價值，以及競賽固定手續費相對較小。小型台積電一跳只有約 100 元，來回手續費與交易稅可能已吃掉一跳毛利。

## 成本與目標價

持有 `Q` 口、均價為 `p_bar` 時，若整批平倉成本估計為 `C_Q`，最低淨利要求為 `pi_target`，多單退出價為：

```text
p_exit = tick_ceil(p_bar + (C_Q + pi_target) / (M * Q))
```

空單則對稱：

```text
p_exit = tick_floor(p_bar - (C_Q + pi_target) / (M * Q))
```

不能直接把「均價加一跳」寫死；商品價格、契約乘數、手續費或稅率改變時，都應重新計算。

## 狀態機

### `FLAT`

- 行情有效且已完成暖機。
- 價差不超過允許值。
- 短期波動沒有超標。
- 在最佳買價掛買單、最佳賣價掛賣單。
- 每方向只保留一張有效入口委託。

### `ENTRY_RESTING`

- 委託價格不因每個 tick 變化而改動。
- 只有在存活時間超過 `quote_ttl_seconds`、中心價移動超過門檻、方向訊號反轉或風險狀態改變時才重報。

### `LONG` 或 `SHORT`

- 一側成交後立即取消另一側入口。
- 重新計算實際均價、費用與退出價。
- 只保留減倉委託，不允許意外反手。

### `HALTED`

- 達每日損失、最大回撤、持倉逾時或行情異常門檻時進入。
- 先退出既有部位，當日不再建立新部位。

## 起始參數網格

以下只適合作為搜尋範圍，不是已驗證最佳值：

| 參數 | 候選值 |
|---|---|
| `quote_ttl_seconds` | 1、2、5 |
| `reprice_threshold_ticks` | 1、2、4 |
| `target_ticks` | 成本公式算出的最小值、最小值+1 |
| `max_hold_seconds` | 5、15、30、60 |
| `entry_offset_ticks` | 0、1 |
| `max_spread_ticks` | 1、2 |

## 驗證指標

- 委託送出後，同價第一次觸及的實際成交率。
- 送單到生效的時間分布。
- 每小時完整循環數。
- 每循環費後淨利。
- 成交後 1、2、5、10 秒價格漂移。
- 持倉時間的中位數、95 分位數與最大值。
- 未完成循環造成的損失占總小額獲利比例。

## 失效條件

- 平台並非每次同價出量都成交。
- 同一帳戶的委託需消耗真實成交量，導致大口數只能部分成交。
- 成交回報延遲使退出單無法及時建立。
- 單邊行情造成入口容易成交、出口長時間不成交。
- 一跳毛利不足以覆蓋完整來回成本。

## 實作原則

- 只能用委託回報確認成交，不可僅依本機行情自行假定成交。
- 撤單與新單必須以委託書號對帳，避免舊單殘留。
- 同一時間每方向至多一張入口單。
- 部位不為零時，預設只允許減倉；若要使用攤平，必須明確切換到有限階梯策略。
